| Gate divergence sensitivity | beta | \gatelam (lambda) |
| Divergence score | D_rot | \Drot |
| Expected profile | mu_expected | \muexp |
| Class weight | alpha_i | \cbw (w_c) |
| CB-loss hyperparameter | beta | \cbbeta |
| Focal exponent | gamma | \focg |
| Number of classes / time steps / batch | 18 / T / B | C / T / B |
